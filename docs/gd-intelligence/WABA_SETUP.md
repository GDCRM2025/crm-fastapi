# WABA setup

GD Intelligence reutiliza `whatsapp_channels`, `whatsapp_contacts`, `whatsapp_conversations`, `whatsapp_messages`, `whatsapp_conversation_leads` y el webhook Meta actual.

Verificar por marca: App ID/secret del servidor, verify token, access token, WABA ID, phone number ID, webhook HTTPS, firma y ventana de 24 horas. El Nivel 1 sólo genera una sugerencia: registra generador, conversación, contexto permitido, aprobador y usuario que envía. No se activa autoenvío ni se almacenan tokens en acciones IA.
